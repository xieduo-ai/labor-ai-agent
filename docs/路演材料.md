# 传智杯路演材料包

> 给非技术队友：你只需要按这个 PPT 大纲做 12-15 页 PPT，再照下面的脚本录 3 分钟演示视频。

## 一、PPT 大纲（12 页）

### P1 封面
- 标题：用工合规 AI Agent
- 副标题：让每一份劳动合同都经得起仲裁庭的检验
- 队伍名 / 学校 / 队员
- 一句 slogan：面向中小企业与劳动者的 AI 劳动法助手

### P2 痛点（为什么做）
- 全国 5200 万中小微企业，90% 没有专职法务
- 每年劳动仲裁案件 100 万+，试用期超期、放弃社保、无补偿竞业限制是三大坑
- 通用大模型答劳动法会编法条——劳动纠纷里"引错一条"的代价是真金白银
- 一句话：关键不是"能答"，是"答得有出处、错了能算出来"

### P3 产品是什么
- 两个端：
  - 👷 劳动者版：口语化问劳动法问题 + 赔偿金计算器
  - 🏢 企业版：上传合同 → 逐条识别风险 → 修改建议 + 法条依据
- 核心承诺：每个回答都附法条原文，不编法条

### P4 产品演示截图（放 4 张图）
- 首页 Hero
- 劳动者问答（带引用卡片）
- 企业合同审查（红黄绿风险清单）
- 赔偿金计算器

### P5 技术架构（重点页，评委吃这个）
画一张流程图：
```
用户口语问题
  ↓
口语→术语扩展（"一倍半"→"百分之一百五十"）
  ↓
双路召回：bge-m3 向量(0.8) + BM25(0.2)
  ↓
RRF 融合 → bge-reranker-v2-m3 重排
  ↓
closed-set 强制引用 + 摘录逐字校验
  ↓
带出处的回答 / 风险清单
```

### P6 评测数据（最有说服力的一页）
| 指标 | 数值 |
|---|---|
| 知识库 | 14 部法规 / 678 条 |
| 口语化问题 Recall@5 | **82.5%**（40 题自建评测集） |
| 合同风险召回 | **100%**（19 个人工埋点全中） |
| 高风险误报 | **0 条** |
| 引用有效率 | **100%**（closed-set 零幻觉） |

### P7 消融实验（技术深度证明）
| 方案 | Recall@5 |
|---|---|
| 纯向量 | 72.5% |
| 纯 BM25 | 42.5% |
| 等权 RRF 融合 | 52.5%（反而掉点） |
| 加权混合 + 重排 | **82.5%** |
结论：重排贡献最大（+10pp），等权融合有害，我们是调过权重的。

### P8 AI Agent 能力
- 智能助手模式：用户说"帮我看看这份合同有没有坑"，Agent 自主判断意图 → 选择工具（qa/review/calculator）→ 展示思考链
- 不是聊天框，是能调度工具的 Agent

### P9 商业模式
- 目标用户：10-30 人小微企业 HR + 刚毕业打工人
- 差异化：免费问答引流 + 9.9 元单次深度合同审查 + 企业版 99/月
- 竞品对比：法天使（合同库为主）、无讼（律师匹配贵）——我们打"免费、带引用、防幻觉"

### P10 上线运营
- 已部署：Vercel（前端）+ Render（后端）
- 运营动作：小红书/抖音/知乎发"试用期被坑怎么办"科普短视频引流
- 用户反馈机制：页面底部留言入口

### P11 未来规划
- 多模态：拍照识别合同（OCR）
- 扩展知识库：各地裁审口径（现在只有湖北）
- 企业端：批量审查、HR 工作台、风险报告导出 PDF
