## 两个已知问题（面试可讲）

1. **"引用有效率 100%" 只证明法条存在，不证明法条选对。**
   A5、B4、B5 引的条文真实存在于知识库，但法理不对（违约金应引劳动合同法第25条而非劳动法第31条）。
   现在的校验只查 `(法律名, 条号)` 是否在库里，查不出"这条能不能支撑这个判断"。
   改进方向：让模型只能从检索出来的 top4 条文里挑依据（closed-book → closed-set），
   选不出来的就标"依据不足"，而不是自由发挥。

2. **B1 漏检**：同一条款里有两个独立问题（试用期期限 + 试用期工资），模型只报了一个。
   改进方向：对高风险条款做"多问题拆分"提示，或在 prompt 里明确"逐项检查、不遗漏"。
