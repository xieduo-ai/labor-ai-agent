## 踩过的坑（别再踩）

- **合同不能放 `data/raw/`**：`src/ingest.py` 会把 `data/raw/*.txt` 全当法规切，合同会被切成"法条"污染索引。合同放 `data/contracts/`。
- **"通知/纪要/指导意见"类文件不是"第X条"格式**（例如劳社部发〔2005〕12 号用的是"一、二、三、"），`ingest` 只认 `第X条`，会解析出 0 条。这类文件暂时不收。
- **`.env` 现在指向硅基流动**（`LLM_BASE_URL=https://api.siliconflow.cn/v1`，模型 `deepseek-ai/DeepSeek-V3`），不是 DeepSeek 官方接口。换回官方只改 `.env`，代码不用动。
- 法规 txt 必须是 **UTF-8**；`ingest` 会依次试 utf-8 → gb18030，但 GBK 文件容易在别处出问题。
- `python -m src.index` 已有索引会直接跳过，改语料后必须 `--force`。
