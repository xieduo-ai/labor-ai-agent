# 部署手册（Streamlit Cloud）

部署完成后，简历里就能放一个能点开的链接。

## 0. 前置

仓库已经包含：`data/processed/`（chunks / embeddings / bm25，共 4MB）。
**不要把它们加回 `.gitignore`**，否则云端没有索引，会直接报"索引不存在"。

## 1. 建 GitHub 空仓库

1. 打开 <https://github.com/new>
2. Repository name：`labor-ai-agent`
3. 选 **Public**
4. **三个勾选框全不勾**（README / .gitignore / license 都别勾）

## 2. 推送（把 `<你的用户名>` 换成英文用户名）

```powershell
cd /d E:\projects\labor-ai-agent
git remote set-url origin https://github.com/<你的用户名>/labor-ai-agent.git
git branch -M main
git -c http.version=HTTP/1.1 push -u origin main
```

第一次推送会要求登录：密码栏填 **Personal Access Token**（GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token → 勾 `repo`）。

若报 `Connection was reset`：把最后一条命令重试 2–3 次，或挂代理后
`git config --global http.proxy http://127.0.0.1:<端口>`。

## 3. Streamlit Cloud 部署

1. 打开 <https://share.streamlit.io>，用 GitHub 登录
2. New app → 选仓库 `labor-ai-agent`，Branch `main`，Main file path `app.py`
3. 点 **Advanced settings → Secrets**，粘贴下面内容（把 sk- 换成你自己的 key）：

```toml
LLM_API_KEY = "sk-你的硅基流动key"
LLM_BASE_URL = "https://api.siliconflow.cn/v1"
LLM_MODEL = "deepseek-ai/DeepSeek-V3"

EMBED_API_KEY = "sk-你的硅基流动key"
EMBED_BASE_URL = "https://api.siliconflow.cn/v1"
EMBED_MODEL = "BAAI/bge-m3"
RERANK_MODEL = "BAAI/bge-reranker-v2-m3"

USE_RERANK = "1"

# 可选：给公开 demo 加个访问密码，防止别人烧你的 API 余额
# APP_PASSWORD = "换成你想要的密码"
```

4. Deploy，等 2–5 分钟

## 4. 验收清单

- [ ] 打开链接，首页两个 tab 都显示
- [ ] 点一个示例问题，能出答案且带"引用的法条"
- [ ] 下载示例合同 → 上传 → 审查，高风险 ≥ 5
- [ ] 手机 4G 打开能跑（验证不是只在你家宽带能用）
- [ ] 配了 `APP_PASSWORD` 的话，先输密码才能进

## 5. 常见故障

| 现象 | 原因 | 处理 |
|---|---|---|
| `索引不存在，请先运行：python -m src.index` | `data/processed/` 没推上去 | 确认 `.gitignore` 里没有这一行，重新 push |
| `Missing credentials` | Secrets 没配对 | 检查 `LLM_API_KEY` / `EMBED_API_KEY` 键名大小写 |
| `401 / 402` | key 失效或余额为 0 | 去硅基流动后台看余额 |
| 页面卡在 "loading" | rerank 模型慢 | Secrets 里把 `USE_RERANK` 设为 `"0"` |

## 6. 更新部署

改完代码后：

```powershell
git add -A
git commit -m "说明"
git push
```

Streamlit Cloud 会自动重新部署。
